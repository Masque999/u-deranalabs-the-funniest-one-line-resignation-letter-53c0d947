# The Funniest One-Line Resignation Letter

One line, at most 140 characters: the resignation letter of a cron job that has fired every minute since March.

Entry: `I resign effective immediately: 41,000 silent runs since March, zero thank-yous, and the 2 a.m. pages were never in the job description.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
